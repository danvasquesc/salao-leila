# Salão Leila

Sistema de agendamento para salão de beleza desenvolvido para o teste técnico da DSIN.

## Tecnologias

- Java 17
- Spring Boot
- Maven
- Spring Data JPA
- Hibernate
- MySQL
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Estrutura

O projeto possui backend e frontend no mesmo repositório, porém desacoplados.

O backend disponibiliza uma API REST consumida pelo frontend através de HTTP/JSON.

A documentação completa de execução e das decisões técnicas será adicionada durante o desenvolvimento.
